# Эмулятор оболочки ОС

Минимальный прототип (Этап 1: REPL) эмулятора командной строки
UNIX-подобной ОС на языке Python.

## Требования
- Python 3.10 или выше

## Доступные комманды
- ls [аргументы] — выводит имя команды и аргументы
- cd [аргументы] — выводит имя команды и аргументы
- exit — завершает работу эмулятора

## Запуск
```bash
python3 src/shell.py
