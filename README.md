# Эмулятор оболочки ОС

Эмулятор командной строки UNIX-подобной ОС на языке Python.

## Этапы разработки

### Этап 1: REPL (ветка `main`)
Минимальный прототип с базовыми командами.

### Этап 2: Конфигурация (ветка `stage-2`)
Поддержка параметров командной строки и стартовых скриптов.

## Требования
- Python 3.10 или выше

## Запуск

### Интерактивный режим (Этап 1)

```bash
python src/shell.py
```

### С параметрами (Этап 2)

```bash
# С указанием пути к VFS
python src/shell.py --vfs /path/to/vfs

# С выполнением скрипта
python src/shell.py --script scripts/test_basic.sh

# С обоими параметрами
python src/shell.py --vfs /path/to/vfs --script scripts/test_basic.sh
```

## Доступные команды

- `ls [аргументы]` — выводит содержимое директории
- `cd [путь]` — меняет текущую директорию
- `pwd` — выводит текущую директорию
- `exit` — завершает работу эмулятора
